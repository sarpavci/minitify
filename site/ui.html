Implementation boundary. The overlay never becomes key or main; its background drags, while controls do not. The separate library is a regular focusable NSWindow so search can accept text. Preserve the overlay’s top edge when changing height, and clamp the resized window to the screen. Browser blur approximates vibrancy; Spotify playback, volume, device discovery, global window level and Space behavior require the native app. This showcase uses local demo state and four tracks from Random Access Memories; it makes no Spotify requests.
